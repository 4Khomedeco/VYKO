# VYKO – Media Downloader & Converter

**by Tan Systems**

YouTube, Instagram, TikTok, Facebook, X ve yüzlerce siteden video/ses indirir; MP3 / MP4 / WAV / M4A'ya çevirir; keser, düzenler, birleştirir, seslendirir.

## İndir

| Platform | Dosya | Not |
|---|---|---|
| **Android** | [Releases](https://github.com/4Khomedeco/VYKO/releases/latest) → `VYKO-x.y.zip` (içinde APK) | Android 8.0+ (arm64). Zip'i "Files by Google" ile açıp APK'ya dokunun. |
| **Windows (web)** | [Releases](https://github.com/4Khomedeco/VYKO/releases/latest) → `VYKO-Web-Dagitim.zip` | Python 3.12+ gerekir; `Kur.bat` sonra `VYKO-Web-Baslat.bat`. |

Kurulumda Android "bilinmeyen kaynak" sorusu sorar; bu, Play Store dışından kurulan her uygulama için normaldir. **5.0 ve daha eski bir sürüm yüklüyse önce onu silin** (5.1 ile imza değişti); sonraki sürümler üstüne kurulur.

## Özellikler

- Linkten indirme: site otomatik tanınır, kalite seçimi (4K'ya kadar video, 320 kbps MP3), oynatma listeleri, altyazı (SRT), kapak resmi gömme
- Dönüştür: MP3 / MP4 / WAV / M4A, çözünürlük düşürme, telefondaki dosyalar
- Kes & Düzenle: dalga/film şeridi editörü, fade, normalize, sessizlik kırpma, hız, ters, sessiz, GIF; birleştirme; zil sesi
- Seslendirme: Microsoft nöral sesler (ücretsiz, 8 dil) ve isteğe bağlı kendi ElevenLabs anahtarınızla ElevenLabs sesleri; Dinle (kaydetmez) / Kaydet
- Ayarlar: kayıt klasörü, tema, dil (TR/EN/DE), **yt-dlp motorunu uygulama içinden güncelleme**, **cookies.txt** ile yaş sınırlı/özel içerik, yeni sürüm bildirimi

## Sürüm bilgisi

`surum.json` uygulamanın "yeni sürüm var mı" kontrolünde kullandığı dosyadır.

## Yasal

Yalnız kendi içeriğinizi ya da indirme izniniz olan içerikleri indirin. Platformların kullanım koşullarına uymak kullanıcının sorumluluğundadır.
Bileşenler: yt-dlp (Unlicense), FFmpeg (LGPL, ffmpeg-kit), Microsoft Edge Read Aloud sesleri, ElevenLabs API (kendi hesabınız).
